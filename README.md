# Statistical Learning Toolkit (`data_analysis`)

A custom Python toolkit designed for data cleaning, exploration, and statistical analysis within Google Colab environments. This library packages common preprocessing tasks into automated, reusable classes.

---

## 📁 Project Structure

This repository is structured as a installable Python package:

* **`data_analysis/`**: The core package directory.
    * `__init__.py`: Package initialization file.
    * `core.py`: Contains main data classes (e.g., `DataInspector`).
* **`pyproject.toml`**: Package installation configuration and dependencies.
* **`README.md`**: Project documentation and quick-start guide.
